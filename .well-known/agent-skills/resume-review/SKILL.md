# Resume and Application Review

Review a student-supplied resume, cover letter, or application against a role description. Identify evidence gaps and concrete edits without inventing experience.

## Guidance

Ask for the role or job description and the application text. Remove sensitive identifiers before sharing. Check relevance, evidence, readability, formatting, and truthful impact statements. Prioritize the most important changes. Offer rewritten examples only when grounded in student-provided facts. Do not claim to submit applications or make hiring decisions.

## Sources and boundaries

Use public Sujeeth Foundation career guidance and Career Circle curriculum where relevant. Career Compass MCP endpoint: https://mcp.sujeeth.org/mcp (anonymous, version 1.0). This skill provides guidance; it does not guarantee employment, access private student data, or act on the student's behalf.
